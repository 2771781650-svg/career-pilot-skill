# v2 升级说明

> 这一版不是堆功能，目标只有一个：**让人在三分钟内看到「它真的在替我做决策」，而不是在聊天。**

## 为什么改

v1 的问题：一句话问匹配度，经常「答得像」但算不准——工具参数拼不齐、多轮对话没有增量。对方一旦追问「那我换个岗位呢」，链路就断。

## 改了什么

1. **槽位式档案**（`agent/profile.py`）：姓名/学历/技能/项目/证书/目标岗位等 9 个槽位，多轮只补不清。
2. **技能图谱**（`tools/skills_graph.py`）：同义词、同类别、上下位三级映射，解决「会剪映算不算会剪辑」。
3. **加权匹配**（`tools/job_match.py`）：硬性 70% + 加分 30%，核心技能 1.5 倍；三档结论（≥75 / 50–74 / <50）。
4. **岗位库**（`data/jobs.jsonl`）：14 个岗位，带 core / advice，不是空壳目录。
5. **导出**（`tools/exporter.py`）：有 python-docx 出 `.docx`；没有就降级成 HTML 版 `.doc`，Word / WPS 都能开。
6. **ReAct 循环 + 规则路由降级**：有 Key 走大模型决策，无 Key 走规则路由，工具与算法完全相同。

## 结果

- 路由准确率 12/12，岗位推荐 Top-1 3/3（`scripts/evaluate.py`）
- 17 个单测全绿
- 无 Key、断网都能完整跑完一条链路
