# 职途 CareerPilot · 产品说明

**形态**：可运行的 AI 智能体（Python，零强制依赖）+ 纯前端可离线版本
**适用**：高职/大学生求职；也适合刚工作一两年想换岗的人

---

## 一、问题定义

求职的真实卡点不是"没有岗位"，而是：

1. **不知道自己差在哪**——简历写满"熟悉 PS、剪映"，但没人告诉他这对应什么岗位、还缺什么
2. **投递靠感觉**——看到"新媒体运营"就投，不知道匹配度只有 40%
3. **面试答不成体系**——被问"讲一次你的作品"，讲成流水账，没有情境-任务-行动-结果
4. **规划是空话**——"我要升本/我要就业"，但不知道这周该干什么

这四件事的共同点：**都需要真的算一遍，而不是聊两句**。所以它不是聊天机器人，而是**会调工具的智能体**。

---

## 二、解决方案

一个智能体 + 七个可插拔工具：

| 工具 | 解决的问题 | 真实算法 |
|---|---|---|
| `build_resume` | 不会写简历 | 按目标岗位分组技能、STAR 化经历、自动投放岗位关键词，输出可直接编辑的草案 |
| `analyze_resume` | 简历差在哪 | 学历/技能/项目/经历/证书五维加权评分，输出缺口优先级 |
| `match_job` | 该投哪个、差多少 | 硬性要求 70% + 加分项 30% 的覆盖率匹配，核心技能 1.5 倍加权 |
| `rank_jobs` | 不知道投啥 | 全岗位算一遍按匹配度排序，取前 3 |
| `interview_question` | 会被问什么 | 按岗位分组的真实面题 + 考察点标签 |
| `evaluate_answer` | 我答得好不好 | STAR 四要素检测 + 量化词检测 + 篇幅检测 |
| `career_plan` | 这周干什么 | 按目标/专业/每周时长按比例切分主线-产出-复盘 |

智能体的职责：判断此刻需要哪个工具、按什么顺序串起来、结果怎么组织成人话。

## 三、技术亮点（都可现场验证）

1. **双引擎降级**
   - 有 API Key：ReAct 循环（思考 → 选工具 → 观察 → 再思考 → 结论），大模型自主决策
   - 无 API Key：内置规则路由，意图识别后直达工具
   - 结论：**不配 Key、甚至断网，功能照样完整可用，只是不调大模型**

2. **零强制依赖**
   核心逻辑只用 Python 标准库（`json`/`re`/`http.server`），克隆下来 `python main.py` 就能跑。Web 界面也是标准库起的服务，不用装 Node、不用装 Flask。

3. **工具可插拔**
   在 `tools/` 下写一个函数 + 在 `tools/__init__.py` 注册一行，智能体立刻学会用新工具（例如接真实招聘 API、接学校就业系统）。

4. **结果可解释**
   每个结论都能追到具体的工具调用（界面会显示"步骤 1 → 步骤 2"），不是随口生成，追问一句能说清算过什么。

5. **多设备不串档**
   服务端按设备会话隔离档案（`/api/health` 可见在线会话数）；前台换设备、两个人同时用，各是各的档案。

6. **页面内自检**
   一键跑 25 条断言（离线引擎、抽取、匹配、简历、模板、人设、记忆、缓存、后端健康与隔离），失败会给原因，不是写死的通过文案。

## 四、上手顺序（3 分钟）

1. `python server.py` → 浏览器打开（或直接用前端离线版，双击 `web/index.html`）
2. 左侧点"说清我的情况"，一句话把学历、技能、目标岗位说进去 → 右上档案条出现内容
3. 问"我投新媒体运营匹配度多少，还差什么" → 展示加权分数与缺失硬性技能
4. 点"对比" → 改前/改后两列同算法算分；点"按右边帮我补齐"，档案真的被补上
5. 点"模拟面试"，选面试官人设 → 答一题出 STAR 点评与追问 → 结束出报告
6. 点"自检" → 看完通过条数；再导出 Word 简历（微信里用"复制简历"带走）
7. 断网刷新：PWA 缓存仍在，功能照跑

## 六、后续可扩展

- **接真实数据**：招聘平台岗位接口，把 `data/jobs.jsonl` 换成实时岗位
- **接学校就业系统**：把本校历年就业去向做成本地知识库，走 RAG
- **群体分析**：聚合一个班/一个专业的简历，输出专业级的技能缺口报告，给学院做课改参考
- **多智能体**：拆成"简历官 + 面试官 + 规划师"三个角色协作
